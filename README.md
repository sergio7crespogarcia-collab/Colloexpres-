# COLLOEXPRES

Aplicación web progresiva móvil para crear listas de compra e interpretar productos mediante IA.

## Estado
MVP en desarrollo. La interpretación con IA requiere configurar OPENAI_API_KEY como variable de entorno del servidor. Los precios de comparación son demostrativos, no precios reales de supermercados.

## Ejecutar
Requiere Node.js 20 o superior.

```bash
npm install
npm start
```

No publiques claves API en el repositorio.
